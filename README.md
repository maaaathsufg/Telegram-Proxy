Telegram-Proxy
Официальный проект. Данный репозиторий является оригинальной разработкой. Проект создан для российских пользователей и предназначен для обхода блокировок Telegram со стороны РКН.

[!WARNING]
Важно. Проект не является форком в прямом смысле. За основу был взят исходный код amurcanov, который был существенно переработан и адаптирован под конкретные задачи. Исходный код данного проекта не публикуется — по причинам, указанным ниже.

О проекте
Telegram-Proxy — это прокси-решение для Telegram, разработанное с учётом реалий российского сегмента интернета. Основная задача — обеспечить стабильный доступ к мессенджеру в условиях активной фильтрации трафика со стороны РКН.

Работа построена на шифровании пакетов: трафик маскируется таким образом, что системы DPI не могут его идентифицировать и классифицировать как трафик Telegram. Соответственно — не блокируют.

Принцип работы
[ Telegram ]  →  [ Telegram-Proxy ]  →  [ Шифрование ]  →  [ Сеть ]  →  [ Серверы Telegram ]
Клиент отправляет запрос.

Прокси перехватывает пакеты и применяет шифрование.

DPI-системы РКН не могут распознать трафик.

Пакеты доходят до серверов Telegram в неизменном виде.

Соединение устанавливается штатно.

Никаких дополнительных настроек на стороне пользователя не требуется.

Почему исходный код не опубликован
Это осознанное решение автора. Публикация исходников в открытом доступе не имеет практического смысла по нескольким причинам:

Базовая реализация уже доступна в открытом виде у amurcanov.

Текущая версия представляет собой переработку с изменениями, не предназначенными для публичного распространения.

Открытый код упрощает задачу блокирующим системам.

Если вам нужен исходный код для изучения — обратитесь к первоисточнику. Если вам нужен рабочий инструмент — используйте готовую сборку.
