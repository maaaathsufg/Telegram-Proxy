# Telegram-Proxy
Телеграм прокси. Этот проект создан для Российских пользователей. Так как РКН режет доступ к telegram: я сделал что то типо прокси для телеграмма. Он работает по шифровке пакетов. Я не приложу исходный код по причине того что нет смысла его выкладывать. Исходный код вы можете взять у amurcanov так как я взял его приложение и переделал.
