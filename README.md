# Telegram-Proxy

> [!IMPORTANT]
> **Официальный проект.** Данный репозиторий является оригинальной разработкой. Проект создан для российских пользователей и предназначен для обхода блокировок Telegram со стороны РКН.

> [!WARNING]
> **Важно.** Проект не является форком в прямом смысле. За основу был взят исходный код amurcanov, который был существенно переработан и адаптирован под конкретные задачи. Исходный код данного проекта не публикуется — по причинам, указанным ниже.

## О проекте

Telegram-Proxy — это прокси-решение для Telegram на телефоне и ПК. Разработано с учётом реалий российского сегмента интернета. Основная задача — обеспечить стабильный доступ к мессенджеру в условиях активной фильтрации трафика со стороны РКН.

Работа построена на **шифровании пакетов**: трафик маскируется таким образом, что системы DPI не могут его идентифицировать и классифицировать как трафик Telegram. Соответственно — не блокируют.

## Принцип работы

| Этап | Что происходит |
|:---:|---|
| 📱 **Telegram** | Приложение отправляет запрос |
| 🔀 **Telegram-Proxy** | Прокси перехватывает пакеты |
| 🔐 **Шифрование** | Трафик маскируется под обычный |
| 📡 **Сеть** | DPI-системы РКН не распознают трафик |
| ✅ **Серверы Telegram** | Пакеты доходят в неизменном виде |

> [!CAUTION]
> **Реакция антивирусов**
>
> Антивирусы часто ошибочно помечают приложение как вирус из-за шифрования пакетов. Если вы не можете установить приложение из-за блокировки антивируса:
>
> 1. Отключите антивирус на время установки.
> 2. Добавьте приложение в исключения.
> 3. Включите антивирус обратно после установки.

## Установка

### Android

1. Скачайте APK-файл.
2. Разрешите установку из неизвестных источников в настройках телефона.
3. Откройте приложение и предоставьте необходимые разрешения.
4. Готово — прокси активируется автоматически.

## Почему исходный код не опубликован

Это осознанное решение автора. Публикация исходников в открытом доступе не имеет практического смысла по нескольким причинам:

- Базовая реализация уже доступна в открытом виде у [amurcanov](https://github.com/amurcanov).
- Текущая версия представляет собой переработку с изменениями, не предназначенными для публичного распространения.
- Открытый код упрощает задачу блокирующим системам.

Если вам нужен исходный код для изучения — обратитесь к первоисточнику. Если вам нужен рабочий инструмент — используйте готовую сборку.
